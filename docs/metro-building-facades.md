# PLATEAU用途に沿う共通外観

元の用途・輪郭・高さを保持し、住宅・共同住宅・業務施設・店舗併用を外観で読み分ける。
一棟ずつBlenderで加工せず、共通部品と配置規則を三帯のストリーミングへ適用する。
窓割り・素材・入口の意匠はSpinwardの設計であり、現実の建物外観の復元ではない。

## 構成

- `src/worlds/plateau/facade-design.js` が用途分類、建物の構成、壁面の役割、住戸の反復を決める。
  `共同住宅` と `店舗等併用共同住宅`、`業務施設`、`住宅`、商業・宿泊・公共・産業用途を分ける。
  用途不明を住宅へ読み替えない。共同住宅の高さから店舗を確率的に付ける旧規則はv2では使わない。
- 住宅は大小の居室・サービス窓、集合住宅は対の窓／フレンチ窓手すり／縦の住戸区分、
  オフィスは連続窓／柱間の窓／大きなガラス面を使う。住宅の対の窓は同じ部屋の色を共有する。
  道路距離と壁の向きから正面・角・側面・裏面を決め、店舗のガラスは正面の地上階へ配置する。
- `assets/plateau/build_facade_kit.py` の `build(target, export, version=2)` で共通部品を生成。
  既存の窓・ドア・帯に、単一ガラス面・伸縮する入口・窓手すりを加えた計6部品。
  Blender MCPの別プロセスを使用。元のv1 blendと現在開かれたGUIシーンは変更していない。
- `FacadeInstances` はv2 kitの場合だけ新規則を使う。v1は既存の配置規則を維持する。
  枠色・ガラスの粗さ・帯や柱の目地をインスタンス属性で渡し、建物ごとのマテリアルやテクスチャを作らない。
  目地は画素より細かくなると消し、遠方のモアレを避ける。
- 近景は立体部品、中景の窓・ガラス・入口は2三角形のパネル。同じ配置と色を使用する。
  LOD境界は装飾部品の寸法から独立させ、元の建物の外接形状と規模を基準にする。
  大きな建物では中景のみ表示距離を延ばす。近景の境界とタイルの取得・常駐上限は拡大しない。
  長い水平帯は円筒周方向8m以下に分け、曲面の建物内部へ弦として埋まることを防ぐ。

## 検証と発見

`qa/plateau/metro-facades.xr.mjs` と `metro-facades.playwright.config.mjs` を使用。
実GPUを確認してからChromeを起動する。WebXRは `playwright-webxr 0.3.0` のエミュレーションであり、実機HMDは未検証。

比較資料は作業領域の `qa-baseline`（旧版）、`qa-final`（検収候補）。
渋谷・東京駅・中野・池袋を同じ四方向から撮影し、描画と常駐量を比較。
`fixtures/metro-facade-views.json` は元データの用途を確認した戸建て・共同住宅の観察点。
道路内包、建物・水面との離隔、壁への視線を元データで確かめて選び、同じ視点で近景／中景を比較する。
既存の `metro-main.xr.mjs` でVRのPlaces操作による三帯移動と高層壁面の見上げも確認する。

独立した画像レビューで、東京駅中景の窓が新たに欠落していることを発見。
旧実装は長い帯の幅を全方向へ加えた過大な球をLODにも使っていた。
帯の分割でその球が縮むと、同じ建物でも窓が早く消えた。元形状に基づくLODへ置換し、
該当2棟の窓が表示されることをブラウザー検査へ追加した。
渋谷で店舗の地上階が無窓化した差分は、PLATEAUの基底とDEMの差で窓を全省略したため。
店舗窓の下端を地面へ追従させ、上端を階高内に制限する検査を追加した。
最初の実GPU検査では頂点属性数の上限超過も発見し、4つのスカラーを1属性へまとめて修正。

関連単体検査は用途・側面の扱い・店舗の地面追従・決定性・円筒分割・Blender部品とLODの整合を扱う。
外部アセットも検査する場合は `SPINWARD_FACADE_KIT` に配信kitの絶対パスを渡す。

## 今回の限界

以下はkit v2時点の範囲。後続のkit v3では、[用途と暮らしが伝わる街路](metro-street-life.md)として一部集合住宅のベランダ・簡略接触、入口と店舗の近景、住戸別の夜間照明を追加した。

- 窓手すりはフレンチ窓用であり、歩いて出られるベランダではない。張り出す床・外廊下・非常階段は未追加。
- 低層商業の階数、建築年代、部屋の用途は実測データから復元していない。店舗併用属性は地上階の意匠へ使う。
- 外壁本体の5色とPLATEAUの輪郭は維持。目地は帯・柱のアクセント部分で、壁全面の写真テクスチャではない。
- 住宅の部屋差はガラス／カーテンの色。夜間照明の色温度・在室状況は今回の実装に含めない。
- 距離が離れれば外観詳細は消え、元の建物形状と色へ戻る。全距離で窓を描く方式ではない。
- 2026-09-25に参照画像（05話0041）を再確認し、民生の間口・縦横区分・壁の余白を参照。
  原画の看板文字、配線、汚れを再現した段階ではない。原画像は成果物へ同梱しない。
