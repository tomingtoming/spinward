# PLATEAU駅舎の共通外観

大宮駅・さいたま新都心駅が無地の塊に見えるという指摘への対応。
従来の外観レシピは「運輸倉庫施設」を一律に除外していたため、駅舎も対象外になっていた。
元の建物形状を保持したまま、鉄道データと一致する建物へ駅用の共通外観を追加する。

## 対象の決め方

`assets/plateau/prepare_station_facades.py` で、N02の駅区間線とPLATEAUの用途・輪郭を照合する。

- 運輸倉庫施設、面積150m²以上、高さ4.5m以上、長辺18m以上。
- 駅区間線から5m以内で、その5mバッファと建物が一定以上重なるもの。
- 直接一致した大きな駅舎に長い境界を共有する運輸施設も、一段だけ付属棟として含める。
  大宮では元データ上で別棟になった低い駅施設を回収する。商業施設やオフィスにはこの推定を広げない。
- 地下駅の位置だけを根拠に地上建物を駅に変えない。用途不明の建物も変えない。
- 帯の切断面を駅の外壁と解釈しない。境界を跨ぐ候補は今回は対象外。

駅と建物の対応は幾何による推定で、元データが直接提供する建物名ではない。
対応するN02のID・路線名、重なり面積、距離、付属棟の根拠を監査JSONへ残す。
今回の生成結果は79駅名・164棟（東44、中央52、西68）、102サイト。
残りの外観カタログは既存レシピをそのまま参照する。

## 外観と費用

Blenderで作成済みの共通キットのガラス・帯部品を再使用する。
駅舎は大きなガラス帯と採光窓、ホーム上屋は上部の細長い窓帯に分ける。
柱割り、屋根端部、基壇、控えめな緑の帯、駅名板を配置する。
庇は元の道路・水面・周囲建物と干渉しないことを確かめた壁だけに付ける。

低い付属棟に接していても、駅舎の上部が露出している場合はその上部だけを仕上げる。
頂部の水平な元三角形から屋根面を取り出し、その内側だけに継ぎ目を置く。
穴のある屋根や傾斜した屋根を、仮の平面で覆わない。
長い部品は円周方向8m以下で分割し、円筒内壁に埋没する直線弦を避ける。

駅名は店舗看板と同じアトラスへ格納し、三帯で一枚を共有する。
部品ごとのPointLight・駅ごとの専用モデル・専用テクスチャは増やさない。
近景は共通ジオメトリ、中景のガラスは既存の2三角形パネル。
各帯の外観常駐上限は24サイト・6MiBのまま。

## 生成とプレビュー

データルート: `/Volumes/BLAZE/Spinward/inland-b-20260924`。
元外観は `derived/facades-v4`、駅対応版は `derived/stations-v6`。
生成スクリプトは出力済みのフォルダへの上書きを拒否する。再生成は別名で行う。

```sh
python assets/plateau/prepare_station_facades.py --root "$DATA_ROOT" --base facades-v4 --output stations-next
```

固定ビルド: 同ルートの `stations-20260925/main-dist-v3`。
ビルド時の追加設定は `VITE_METRO_FACADE_KIT=/stations-v6/kit.json` と
`VITE_METRO_FACADE_CATALOG=/stations-v6`。
既存のfinish-v1、render-v2/lowrise、roads-v2も引き続き有効にする。

## 検証と限界

- 分類、隣接低層棟、平坦屋根、部品境界、住宅部品の混入防止、アトラス共有・解放を単体検証。
  関連Bunテスト16件、Pythonテスト5件、型検査、固定ビルド成功。
  全体のBunテストは中断され未完了。途中で既存のpublicPark elysium/64000が既定5秒を超えてタイムアウトしたが、
  並行処理が終了した後の単独再試験は1.47秒で成功した。
- 大宮・さいたま新都心の地上と上空、夜、近中景、VR左右眼と頭の傾き: 6シナリオ成功。
- 固定ビルドをChromeの実GPUで使用。`playwright-webxr 0.3.0`、両眼間隔64mm。
  実機HMDは未検証。
- 既存カメラには身体位置から1.8mの目線オフセットがある。検査はURLの身体位置と実際のrig位置を照合する。
- 独立画像レビューで大宮の屋根継ぎ目に斜めの欠落を発見。
  元データの水平屋根に投影由来の26mmの高さ差があり、20mmの抽出許容を超えていた。
  許容80mmに修正し、傾斜屋根を平面化しないテストとcm単位の高さ差の回帰テストを通した。
- 画像証跡は `stations-20260925/before-final` と `qa-v3`。
  視点は `qa/plateau/fixtures/metro-station-views.json`、検査は `qa/plateau/metro-stations.xr.mjs`。

今回の意匠はSpinwardの設計であり、現実の駅の外観・出入口・屋内の復元ではない。
元のLOD1の閉じた建物形状は残るため、ガラスの先へ入れる駅や、ホーム下の空間はまだ実装していない。
79駅をすべて同じ精度で目視確認したわけではなく、重点確認は大宮とさいたま新都心。
街全体の夜景については、[夜景の調査と次の改善](metro-nightscape.md)を参照。
