# 物流JCTの上下分離

南部物流JCTを改設計し、道幅・桁厚を含む干渉8組を0へ減らした。
全7ICの干渉0も維持。独立した立体設計の検査であり、現行コロニーの道路・交通へは
未適用。単一の合流路面、支持構造、車線運用まで完成したJCTではない。

## 参照と採用範囲

高架下面・支持柱、下の車道と分離した歩行帯を確認。下の動線に空間を残す上下関係を
採用する。資料はJCT配置図ではない。今回の三層配置・寸法はSpinward独自の案で、
人物・車両の固有意匠、画像内の文字は採用していない。原本の変更・新着走査・同梱なし。

## 4方向と高さ

| 方向 | 構成 |
| --- | --- |
| 南から物流支線へ | 本線と同じ高さ10.2mで、近い側へ曲がる |
| 物流支線から北へ | 本線と同じ高さ10.2mで、近い側へ合流 |
| 北から物流支線へ | 約17.2mまで上り、反対車線を越えて支線へ戻る |
| 物流支線から南へ | 約3.2mまで下り、本線の下を通って本線高さへ戻る |

分岐・合流は中心の前後600m。遠い側の折返しを本線中心より85m外へ置き、
長い接続区間で7m上昇／下降する。ランプ両端90mは本線・支線と同じ高さを保持。
上下の曲線にはその両端を除いた弧長を使い、平面の合流中に先に高さだけを変えない。
中心線が平面上で交わっても接続を追加せず、4方向を明示した有向辺として扱う。

交差の最小空間は5.398m（上の道路の桁厚1mを引いた値）。上下ランプ同士は
12.968m以上。JCT最大勾配2.028%未満、ICを含む全体は5.906%で6%以内。
前段と同じ有限幅の多角形切抜き・桁厚・共通ノード60m／高さ差15cmの判定を維持。
旧案を `proposedBandExpressway('direct')` で生成し、同じ検査器が8組を検出する
対照を残す。4.5m空間・6%勾配は今回の設計目安で、道路規格の引用ではない。

短いハンドルで曲げれば高さ検査だけは通るが、折返しが急すぎるため曲線を緩めた。
現在は連続する3つの中心線ノットで求めた半径が全4ランプで30m超、最小約30.90m。
ノットからの離散評価であり、連続曲率や運転速度を認定するものではない。

下段も圧力外殻の上にあり、桁下面は最低でも約2.2m。外殻を掘らない。
下段の下を一般車・歩行者に開放する設計ではなく、JCT用地内に地上道を生成しない。
地上交通を通す指定箇所は別の予約・検査を使う。支持柱の配置はまだ含んでいない。

## 支線と一般道

支線の取り付けをJCT中心の高さにそろえ、西向きの短い直線から滑らかなS字で
既存の渡河区間へ戻す。物流支線は約2.287km。7つの地上ゲートの座標・担当地区・
物流支線の渡河位置は変更していない。分岐部と支線の新用地を先に予約し、一般道を再生成。
整理後629区間・190.947km、接続成分1、独立閉路46、鋭角0・20m未満の分岐点間0。
未接続の地区・未配分需要0を維持する。7ゲート間42方向、IC閉鎖・JCT閉鎖の経路検査も継続。
