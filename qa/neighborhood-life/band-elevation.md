# 川・橋・専用道路の高さ

全域の平面道路案を、河床・護岸・上下の歩道・橋・高架の高さを持つメッシュへ進めた。
現行の居住中コロニーへは未適用。独立した立体化の検討と検査器であり、
走行可能な高速道路や、全域の河川・歩道を完成させたものではない。

## 参照と解釈

確定manifestの `izma-ep04-0024` を元の1920×1080で再閲覧し、原本SHA256
`74330871397a3b589db285d9d85f3c3e8323ff19547b5929454a827d67df056c` と照合した。
上の街路・橋、低い護岸歩行帯、水面という上下関係を採用する。石造アーチの造形・
人物・空の白い筋を複製せず、川筋・寸法・構造はSpinward独自の案。
新着の走査、資料の変更・同梱は行っていない。

## 北部の接近路

前段で残った0.855°の合流は、幹線が途中の交差点でグラフ上の別区間に分割され、
合流先を一本の区間からしか選んでいなかった。進行方向が30°以内で続く同種の
幹線を、固定点または探索距離の上限までたどる。すでに路面幅の中で重なる
接続点は従来の局所統合を先に使う。遠い並走路を、その先の固定ICへ接続し直す。
固定点・保留地・指定横断・従来到達できた需要・接続成分を守る受入検査は継続する。

原案633区間から整理後626区間、鋭角8→0、20m未満の分岐点間6→0。
編集15回、一般道延長191.544km、接続成分1、独立閉路46。
短い次数2の曲線サンプルを全部消す意味ではない。貪欲な整理であり最適解の保証はない。
道路幅の切替、曲率、車線の合流・停止制御・運転可能性は別の工程。

## 河川の断面

河川予約と高さの処理は `proposedBandRiver` / `bandRiverCentre` を共用する。
既存の局所河川と同じ考え方で、圧力外殻の高さ0より上に土と河床を載せる。
外殻に穴を開けたり、全市の地面を一律に持ち上げたりしない。

| 低い護岸の土／歩道 | 1.20／1.26m |
| 上の護岸の土／歩道 | 5.00／5.06m |

| 橋の道路歩道 | 5.32m |

水路は幅19m。両側に低い歩行帯と垂直の護岸を置き、川筋から30mの位置より外で
125mかけて高さ5→0へなだらかに戻る。渡河路は同じ縦断を使い、両端で外側の
道路に高さ0.2mで接続する。円筒面の地形と道幅の中の小さな横方向差も保持する。
横断方向の最大勾配は6%。曲がった川筋を含む任意方向の地表勾配や、
車両の乗り心地・排水勾配を保証する道路規格ではない。

橋下の護岸歩道から桁下面まで3.39m、水面から4.00m。現在の検査表示は
幅25.5m・中央60mの単純な床版下面であり、60mを無支持で架けられると
構造検証したものではない。桁形式・橋台・支柱・柵・護岸上下のアクセスは残件。
既存橋の位置は基準にするが、現在の局所橋の斜角をまだ全域案へ移していない。
水面は静的な面であり、水流や水理のシミュレーションではない。

土は上面だけでなく河床、底面、両端の断面を閉じる。護岸の段差で端面の辺が
途中に接続していた問題を、段差の各高さで端面を分割して修正。
川筋の折点を含む40mの対照試料で、全メッシュ辺が2枚の面に接続し、
全頂点が高さ0以上にあることを確認する。
路面は所有が確定した多角形を5m以下に刻んで高さを与え、一本の長い三角形で
上り坂と下り坂を飛び越えない。橋の対照検査では三角形中心の高さと縦断の差が7mm未満。
これは全域の路面誤差や、地形との物理コリジョンを保証する試験ではない。

## 専用道路の成立条件

本線・支線は上面10.2m、桁厚1m。片方向2車線は幅9m、1車線ランプは5.5m。
ICの地上ゲートは0.2mへ連続して下り、JCTの一部へ仮の7mの上昇を与える。
始点・終点の高さは明示したノードに合わせる。上下線間のXY交差でグラフを接続しない。
**この仮の縦断は未成立。描けることを通行可能と読み替えない。**

アーク長5m以下のサンプルから道幅のある三角形を作り、同じ上面を描画と検査へ渡す。
64mセルで候補を絞り、多角形を切り抜いて幅の重なる全頂点で上下差を調べ、上の
道路の桁厚を引く。途中で上下の順序が反転する重なりも不成立として扱う。
一般の長方形を使う対照検査では、中心線が交差しない横ずれ8mの道路端の干渉を検出する。
円筒へ曲げる前の展開座標の検査なので、実際の局所鉛直方向の桁下高の微差は次段。

| 現在の案の検査 | 結果 |
| --- | ---: |
| 最大縦断勾配 | 約3.986% |
| 6%を超える区間 | 0 |
| 高さ・合流形状が未成立の道路組 | 43 |
| うち、共通ノードを持たない道路組 | 12 |
| 使用中の一般道の指定立体横断 | 4か所 |
| 上下線との幅の重なり | 8組、桁下9m |

4.5mの車両空間、6%の勾配は今回の設計上の目安であって道路規格の引用ではない。
共通ノードの60m以内で高さ差15cm以内の重なりだけは接続域として除外する。
この範囲にも単一の路面所有・ゴア形状・車線の接続を作る必要がある。
43は道路の組数で、物理的に異なる地点が43か所あるという意味ではない。
反対車線を横切るICランプは、桁の中へ入ってしまう。JCTにも反対車線・別ランプとの
不足がある。共有ノードのある組でも、先へ進むと高さが食い違う。
閾値を緩めて合格にせず、ランプの横方向の経路・分岐位置と縦断をまとめて修正する。
使用されなかった立体横断候補1か所、全一般道との幅の監査、支柱の侵入は検証対象外。

## 再現と費用

```sh
OUTPUT_DIR=/absolute/path/to/evidence bun qa/neighborhood-life/band-elevation.ts
```

`index.html`・`viewer.js`・`scenes.json`・`summary.json` を生成する。
川と橋、一般道と高架、IC、JCTを低視点・俯瞰・横・真上で確認できる。
3Dは高さ・幅を強調しない。折りたたんだ橋の縦断図だけ高さを15倍にして明記する。
未解決位置は赤と橙。GPU表示はsoftware rendererを拒否する。
これは独立した検査用の照明で、昼夜の現行コロニーの見え方の検査ではない。
初回レビューの指摘を受け、選択場所に応じた寸法、両岸の歩道からの近景、
IC/JCTの干渉位置へ寄る視点と、その道路組の最小空間を表示した。
表示切れを防ぐため、1280×720でタイトル・描画・説明・寸法・状態を収める。
撮影は視点の変更と保存を別の呼び出しにし、2 animation frames後の描画状態を
読んでから行う。初回ICの俯瞰・近景が同じだった画像は最終証跡から除外する。

検査用の影に細かな縞が出るため、同じ形状・カメラで影だけを外す比較を追加。
光源とmaterialの状態も更新した比較では縞が消える。影ありを完成した照明品質とは
扱わず、形状の確認は影なしも併用する。局所の動的ちらつきゼロを保証した録画ではない。
土の上面に見えた細かな斑は、検査カメラのnear/farを2/6000mに限定して深度精度を
保ち、修正後の静止画で再確認した。現行アプリのカメラ設定は変更しない。

全39.84kmの河川を一括生成すると、土271,308、水3,986、歩道15,944、
草の上面103,636、計394,874三角形。下面など埋まる面も含む。
