# 全域の貯水・回収設備

3本の居住帯それぞれの水路上流に貯水設備、下流に回収設備を配置する。
既存の端部予約位置を使い、保存済みの地形、水面、端部道路から高さを採寸した。
これはSpinward独自の環境設備案であり、作品資料の施設を復元したものではない。
飲料水・生活排水は別系統とする設計で、現在の模型は河川循環水を扱う。

証拠は `qa/webxr/evidence/colony-waterworks-20260920/` にある。
v4を正規の `izmaColony*.json` とnative資産へ導入済み。既存の地形・街路・建物・
公共空間等が変わらないことを差分検査し、導入前のファイルを保存した。
通常5192も検証済みの水施設v4へ切替済み。隔離候補5300も保持する。
`canonical-waterworks-installed.json` が導入記録、`normal-preview-waterworks.json` が
HTTP経由で照合した配信ハッシュと所有PIDの記録。

- native v4：6施設、近・中・遠の3段階LOD。
  長方形の貯水槽、円形の回収槽、ポンプ棟、配管、管理路、点検階段・橋。
  施設の接地面と管理路は固定層として地区読み込みに含める。
- 地形と既存敷地の重なりを確認。配管終端は図上の高さではなく、実際の水面内に置く。
- 固定描画15,120三角形、近景22,095、中景17,484、遠景7,170。
  近景と中景を含む1施設の取得サイズは最大317,833 bytes。
- 階段各段、橋、管理路と周辺15,651点で支持高と局所衝突費用を検査。
  不整合・予算超過ゼロ。最大25物体／2,356三角形（上限32／4,096）。
  `integration-v4/waterworks-geometry-audit.json`。
- 導入後の `bun run build`（TypeScript検査とproduction build）は成功。
  配信JavaScriptは検証済みv4候補と全ファイルのハッシュが一致する。
  導入後の地区読み込み・4世界切替のVR再検査7件は成功（2.3分）。
  遅延・取得失敗時の身体保留、手首操作による復帰も含む。
  `canonical-xr-regression.log` と `xr-canonical-regression/` に保存。
  導入後の全体単体試験は1,202件成功・失敗0（210ファイル、1,029.90秒）。
  `canonical-unit.log` に保存。通常5192から取得したHTMLと3つのJavaScriptは
  この検証済みproduction buildとハッシュが一致する。
- native画像の独立レビューで橋の床重複を発見し、v3で解消。
  上面・側面・階段接続を再確認。Cの槽の点状表示は植生の茎で、近接画像で確認。
  河川管の末端は水面に届く。途中の地面による遮蔽と連続性はアプリでも確認する。

全体ソース `8d84a3e8e73a5414ba52f62602f77de16be6f7f363708c2d9aa0612fcc4cbf20`、
実行時 `4eb4d6b6a985fa694ff6b3da4edbd37a5140fff0f2b4b56dbabb97567151267b`。
`frozen-build-v4.json` に配信JavaScriptとnativeのハッシュを保存した。

地下の加圧還流系統は図上の線からnative meshへ進めた。各帯の36.4km本管3本と
施設への支管・槽への枝管・ポンプ棟内の集合管を合わせ36メッシュ。
全ての管の連続性・両端以外の開口がないこと、各帯の回収ポンプから貯水ポンプと
各槽までの接続を保存済みBlender形状から検査した。埋設本管・施設支管は
121,719点で被りを確認し、最小2.221m。検査範囲と各管の結果は
`candidate-v4/waterworks-native-audit.json`。地下管は地表描画・衝突から除き、
全体設計データとnative資産に保持する。流量・容量・水理の成立は未検証。

点検路には支柱付きの照明174基を設けた。native側で灯具の支持を検査し、
アプリでは既存の近距離6灯枠を共有する。遠い174灯を全て点光源として動かさない。

実際のplaywright-webxr 0.3.0でA貯水・B回収・C貯水の階段往復3件が成功（1.1分）。
9枚の両眼画像も独立確認し、見える範囲に大きな床欠落・断絶・片眼だけの欠落はない。
v3で暗かったCの夜間階段は照明追加後のv4を比較し、踏面と段差を視認できることを
独立確認。近傍照明の作動と6灯上限も実際のXR移動中に確認した。実機は未測定。
6施設への到着と3俯瞰を昼夜で撮影し、18ケースが成功、ページ・取得エラーなし。
Apple M1 Pro / ANGLE Metalの短いDesktop計測で中央値16.7ms。実機VR性能の値ではない。
記録は `xr-v4.log`、`xr-waterworks-v4/`、`app-v4/desktop/report.json`。

昼の到着画像ではポンプ棟の壁が視界を塞いだため、書き出しコードの訪問点を建屋の
端より先に移した。v4のA貯水・B回収をv3と比較し、到着時に設備と階段が見えることを
確認した。ポンプ棟内部、飲料水・生活排水の別系統、容量・流量シミュレーションは未完。
